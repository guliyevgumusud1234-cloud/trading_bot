📋 GEREKLİ ADIMLAR (Sırayla):

1️⃣  BINANCE API ANAHTARI ALIN (10 dk)
   └─ Testnet (Önerilen): https://testnet.binancefuture.com
   └─ GitHub ile giriş yapın
   └─ API Key oluşturun
   └─ ✅ Enable Reading ve Futures - AÇIK
   └─ ❌ Enable Withdrawals - KAPALI (Güvenlik!)

2️⃣  .env DOSYASI OLUŞTURUN (5 dk)
   └─ cp .env.example .env
   └─ nano .env
   └─ BINANCE_API_KEY ve SECRET'i girin
   └─ BINANCE_TESTNET=true yapın

3️⃣  TELEGRAM BOT KURUN (10 dk - Opsiyonel)
   └─ @BotFather'a gidin
   └─ /newbot komutunu kullanın
   └─ Token'ı .env dosyasına ekleyin
   └─ Chat ID'yi bulun ve ekleyin

4️⃣  DATABASE BAŞLATIN (2 dk)
   └─ docker-compose up -d timescaledb redis
   └─ # veya
   └─ brew services start postgresql@15

5️⃣  SİSTEMİ TEST EDİN (1 dk)
   └─ source venv/bin/activate
   └─ python setup_check.py
